# Восстановление исходного Lumen — незавершённая работа

Требование пользователя: перенести приложение three6mafia/lumen на Kotlin, сохранив интерфейс, ссылки и поведение. Новый дизайн не разрешён. APK 1.0.0 не выполняет это требование.

Эталон: исходный checkout `/workspace/lumen`, commit ca1d93967da8d8414db1f98e44b632a16d90f507, компоненты и стили мобильной и TV версий. Дополнительный визуальный эталон: скриншоты в README исходного репозитория.

Изменено в этой рабочей ветке:

- Mobile: исходные пять действий нижней панели (Home/Search/Bookmarks/Recent/Account); TV: боковая навигация. Удалён придуманный заголовок LUMEN и верхняя лента всех экранов.
- Палитры и размеры взяты из src/theme/colors.ts, colorsDark.ts, text.ts. Вкладки домашнего каталога размещены над нижней панелью, как на исходном скриншоте.
- Сетка мобильных постеров: три колонки, отношение сторон 166:250, скругление 12, подписи и бейджи. Иконки навигации перенесены из точных Lucide path data зависимости оригинала (ISC).
- Начат перенос панели поиска и перехода из профиля к отдельной форме входа по SearchScreen и LoginForm.
- Для выбранного пользователем rezka.ag отключён прежний официальный режим по умолчанию. Старый default исправляется при обновлении; списки URL зеркал и CDN не меняются, custom mirror и cookies сохраняются. Это отличие от исходной настройки officialMode зафиксировано, его нельзя считать полным совпадением поведения.

Не завершено: детальный перенос FilmScreen, всех возможностей Player, Account, Settings, модальных окон, интерактивности и анимаций; полный визуальный прогон всех экранов, мобильной и TV навигации; проверка входа/каталога/поиска/видео реального сервиса. Исправления навигации не означают соответствия всего UI оригиналу.

## Реальный rezka.ag

Команда: `scripts/build.sh -PliveRezka :app:testDebugUnitTest --tests com.lumenkot.app.LiveRezkaTest`.

Фактический результат в этой среде: **1 тест выполнен, 1 ошибка** — `java.io.IOException: Unexpected response code for CONNECT: 403`. curl также сообщает `CONNECT tunnel failed, response 403` от прокси. HTML rezka.ag не получен. Тест не использует fixtures или запасное зеркало. Подробности: verification/live-rezka-failure.xml.

Обычные JVM тесты не включают LiveRezkaTest; это явный отдельный сетевой прогон, а не условно проходящий или пропущенный live-тест. Его неуспех блокирует утверждение, что реальный сервис работает.

APK этой ветки не следует выдавать за завершённый перенос, пока не закрыты указанные расхождения и реальная проверка.

Первый этап этой ветки: assembleRelease и lintDebug прошли; 14 автономных JVM-тестов прошли (6 ParserTest + 8 NativeRuntimeTest). Это не заменяет упавший live-тест и не подтверждает полного визуального соответствия.

Исправления следующего этапа — видео, вход и основные действия плеера — описаны в [PLAYBACK_FIXES.md](PLAYBACK_FIXES.md).
