# Проверки и границы переноса

Исходная ревизия `three6mafia/lumen`: `ca1d93967da8d8414db1f98e44b632a16d90f507` (master). Исходный checkout не изменён.

## Подтверждено в этой среде

- `assembleDebug` и `assembleRelease` завершаются успешно.
- `testDebugUnitTest`: **11 тестов, 0 ошибок, 0 пропусков**. Проверены каталог/пагинация, сезоны и серии, inline-видео, декодирование замусоренного Base64, неизменность URL и субтитры. Дополнительно Robolectric проверяет создание Activity в светлой и тёмной теме, настоящий HTTP к MockWebServer, сохраняемые cookies/изоляцию доменов, поиск/комментарии и историю.
- `lintDebug`: **0 ошибок**. Остаются рекомендации по ресурсам/локализации, PiP, KTX и версиям библиотек; проверки не отключались, baseline не добавлялся.
- `apksigner verify`: устанавливаемый APK подписан схемой v2. Используется локальный отладочный сертификат; это не production signing key.
- `aapt dump badging`: package `com.lumenkot.app`, min SDK 24, target SDK 35, имя `LumenKot`.
- В APK нет React Native bundle или native runtime. UI написан на Kotlin/Android Views, видео воспроизводит Media3, HTTP/HTML обрабатывают OkHttp/Jsoup.
- Реестр исходных URL сохранён в `original-links.json`. Зеркала, CDN, статический сервер изображений, ссылки проекта и JSON обновлений оригинала не перенаправлялись на другие сервисы.

## Проверка на устройстве

В `app/src/androidTest` подготовлены интеграционные тесты для локального сервера `tools/smoke_server.py`: HTTP-каталог/фильм/потоки/поиск/комментарии, cookie persistence и разделение доменов, история, запуск Activity, продвижение позиции Media3 при воспроизведении MP4. На Android 15 / API 35 AOSP ATD x86_64 выполнены **5 тестов, 0 ошибок** (`OK (5 tests)`). Media3 действительно продвинулся по тестовому MP4; проверена позиция >500 мс и длительность ≥3 сек.

Первый прогон имел 3 сетевых сбоя, потому что ATD не имел маршрута к `10.0.2.2`. После настройки `adb reverse tcp:8765 tcp:8765` и loopback-адреса все 5 тестов прошли. Эта коррекция затрагивает только тестовый маршрут, не штатные зеркала приложения.

## Что ещё не подтверждено

- Доступность реальных зеркал/CDN и работа входа с реальным аккаунтом. Эти сервисы зависят от региона, блокировок, подписки и текущей HTML-разметки.
- Доступ к исходному Firebase-проекту из нового application ID и синхронизация с оригинальным Lumen. Сохранены проект и структура `timestamps`/`savedTime`; возможны серверные ограничения, которые нельзя проверить без включения функции с реальным аккаунтом.
- Физические Android TV, разные пульты, SD-карты, долгие загрузки, HLS/субтитры реального провайдера и восстановление после убийства процесса.
- Пиксельное совпадение UI с оригиналом: это нативный интерфейс с системными диалогами и фокусом, а не автоматическая конверсия JSX.

## Известные отличия

- Интерфейс этой версии русский; поддерживаются системная, светлая и тёмная темы. Полный набор переводов, анимаций и тонких настроек оригинала ещё не перенесён.
- Загрузки используют системный DownloadManager и каталог приложения. HLS доступен для просмотра; для скачивания требуется MP4. Постеры и субтитры могут скачиваться рядом с MP4, доступны настройки внутреннего/внешнего накопителя. Работа со съёмной SD-картой не проверена.
- Трейлеры и внешние ссылки открываются системным приложением. Автообновление из прежнего JSON не устанавливает APK оригинального React Native Lumen поверх LumenKot: ссылка доступна в настройках как обновления оригинала.
- Форматирование комментариев отображается нативным HTML renderer; спойлеры скрываются и раскрываются отдельной кнопкой. Это отличается от разметки и отдельных жестов React Native UI.
- Нативная версия не переносит существующую локальную MMKV-базу оригинального приложения; используются отдельные настройки/история/cookies. Серверные закладки доступны после входа в тот же аккаунт.

Эти отличия означают, что сборка представляет нативный перенос основных сценариев, **а не завершённое соответствие всем функциям оригинала один к одному**.

## Публикация

Подготовлен отдельный локальный Git-репозиторий `LumenKot`. Создание/отправка репозитория GitHub не выполнены: API `api.github.com` отвечает Forbidden при действующей сетевой политике. Домен добавлен в черновик сетевых настроек; для продолжения необходимо применить его в настройках среды и повторно проверить доступ. Наличие локального origin не означает существования репозитория GitHub.
