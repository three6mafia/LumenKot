# LumenKot

> **Перенос не завершён.** Опубликованный APK 1.0.0 — прототип с изменённым интерфейсом. Он не соответствует запросу сохранить интерфейс и поведение исходного Lumen. Предыдущие тесты с искусственными ответами не подтверждают работу реальных зеркал. Восстановление по `three6mafia/lumen` ведётся в ветке `fix/source-ui-parity`; эта ветка также пока не является готовой заменой.

Нативный Android-клиент на **Kotlin**, перенесённый из [Lumen](https://github.com/falcofemoralis/lumen). Android 7.0+ (API 24), телефоны и Android TV. В приложении нет Expo, React Native, Metro, JavaScript-движка или WebView-обёртки.

## APK

Готовая устанавливаемая сборка: [`artifacts/LumenKot-1.0.0.apk`](artifacts/LumenKot-1.0.0.apk). Контрольная сумма находится рядом в `SHA256SUMS`.

Идентификатор `com.lumenkot.app` позволяет установить приложение рядом с оригинальным Lumen. APK варианта release подписан локальным **отладочным сертификатом** для установки и тестирования. Для дальнейших обновлений используйте тот же сертификат; для публикации приложения настройте собственный release signing. Закрытые ключи не включены в Git.

## Что перенесено

- Системная, светлая и тёмная темы. Нативные экраны каталога, новинок, поиска с голосовым вводом и подсказками, жанров/годов, подборок, фильма и фильмографии.
- Прежние зеркала, официальный режим, CDN, User-Agent и пути запросов. [Реестр исходных URL](docs/original-links.json) сохранён для сверки. Ссылки GitHub и Telegram ведут туда же, куда в оригинале.
- Нативные OkHttp/Jsoup, вход в аккаунт и сохраняемые cookies с проверкой домена, закладки, история, новые серии, комментарии и оценки.
- Переводы, сезоны, серии, качество, субтитры, MP4/HLS-плеер Media3, скорость, масштаб, перемотка, PiP, сохранение позиции и переход к следующей серии.
- Загрузка MP4, постеров и субтитров через системный DownloadManager, выбор накопителя, прогресс, открытие и удаление файлов, локальная история.
- Необязательный Time share через исходный Firebase-проект и коллекцию `timestamps`; по умолчанию выключен.
- Управление стандартными Android focus/D-pad и TV launcher/banner.

Это самостоятельная реализация нативного интерфейса. Пиксельное совпадение с React Native, все жесты/анимации и все варианты устройств не подтверждены. Подробные ограничения и результаты проверок — в [docs/VALIDATION.md](docs/VALIDATION.md).

## Сборка

Нужны JDK 17+ с `javac`, Android SDK Platform 35, Build Tools 35.0.0. Gradle Wrapper 8.13 включает официальную SHA-256 дистрибутива.

```sh
# Укажите свой путь к SDK в local.properties (файл не входит в Git):
printf 'sdk.dir=/path/to/android-sdk\n' > local.properties
./scripts/build.sh
```

Скрипт собирает `app/build/outputs/apk/release/app-release.apk`, запускает JVM-тесты и Android Lint. В облачной среде он использует существующие HTTP(S)-proxy и доверенный CA, сохраняя проверку TLS. В обычной среде можно также запускать `./gradlew assembleRelease testDebugUnitTest lintDebug`.

```sh
adb install -r artifacts/LumenKot-1.0.0.apk
```

Готовая сборка не требует Node.js или отдельного сервера разработки.

## Проверки на устройстве

Синтетические ответы API и генерация тестового видео описаны в [tools/README.md](tools/README.md). Интеграционные тесты используют локальный fixture-сервер и не обращаются к реальным аккаунтам. Для проверки реальных сервисов выберите доступное зеркало в настройках; официальный режим, как в оригинале, использует `https://hdrzk.org`.

На Android 12+ для открытия HTTP(S)-ссылок через LumenKot может потребоваться включить поддерживаемые ссылки в системных настройках приложения. Подтвердить владение сторонними доменами с новым package ID и сертификатом невозможно со стороны этого репозитория.
